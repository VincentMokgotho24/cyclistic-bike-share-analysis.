# Cyclistic-bike-share-analysis.
This is my Google Data Analytics Capstone Project. The goal was to analyze 12 months of historical bike-share data (5,824 bikes, 692 stations) to understand how annual members and casual riders use Cyclistic bikes differently.

### Tools Used

-Python (Pandas, NumPy) for data cleaning and analysis

-Jupyter Notebook

-Tableau for data visualization

### Key Insights

-Casual riders ride significantly longer than annual members.

-Members ride primarily for commuting (peaks at 8 AM and 5 PM on weekdays).

-Casual riders ride mostly for leisure (peaks on weekends).
